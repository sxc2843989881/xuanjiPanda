## 二、融合架构设计

### 2.1 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    V200-极光 多因子增强轮动                    │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  第1层: DC方向确认 (B2v6)  ← T值z-score                     │
│  第2层: DCD方向冷却 (B2v6)  ← 换向冷却期                    │
│  第3层: 弱信号过滤 (B2v6增强) ← T值+斜率+均线能量           │
│  第4层: 多周期动量 (ETF-Mega7) ← [1,3,6]月动量合成          │

│                                                              │
│  缓冲层: 排名缓冲 (DAO-Quant) ← 掉出Top N才换               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 与B2v6的差异

| 维度 | B2v6 | V200-极光 |
|------|------|-----------|
| 标的数量 | 2个（成长100/价值100） | 2个（成长100/价值100） |
| 动量因子 | 单周期B2动量（ms/ml） | 多周期合成动量[1,3,6]月 |
| 均值回归 | 仅BIAS超买清仓 | BIAS+RSI+布林带三重判断 |
| 成交量 | 无 | 量比调整因子权重 |
| 缓冲机制 | 无 | 排名掉出Top N才换 |
| 决策系统 | 方向判断+过滤 | 方向判断+评分+过滤 |

### 2.3 核心创新点

**创新1: 多周期动量合成 (取ETF-Mega7精华)**
- 1个月动量: 短期趋势捕捉
- 3个月动量: 中期趋势确认
- 6个月动量: 长期趋势方向
- 用波动率进行风险调整，剔除高波动噪音

**创新2: 均值回归三重预警 (取Mean Reversion精华)**
- BIAS乖离率: 偏离均线>19%清仓（保留B2v6）
- RSI顶背离: 价格新高但RSI未新高 → 撤退信号
- 布林带位置: 价格>上轨+RSI>80 → 双重确认卖出

**创新3: 成交量因子确认 (取ETF-Mega7精华)**
- 量比 = 5日均量/20日均量
- 放量上涨时提高动量权重
- 缩量下跌时确认底部

**创新4: 缓冲机制 (取DAO-Quant精华)**
- 仅当评分排名掉出前2名时才换仓
- 减少50%+的无效切换

## 三、因子计算详细设计

### 3.1 动量因子 (40%权重)

```
Momentum_Score = 0.5 × M1 + 0.3 × M3 + 0.2 × M6
  其中 M1 = 1个月动量 / 1个月波动率 (风险调整)
       M3 = 3个月动量 / 3个月波动率
       M6 = 6个月动量 / 6个月波动率
```

### 3.2 均值回归因子 (30%权重)

```
MR_Score = 0.4 × RSI_Score + 0.3 × BIAS_Score + 0.3 × BB_Score
  其中 RSI_Score: RSI<20→100分, RSI>80→0分, 线性插值
       BIAS_Score: BIAS负值越大→越高分（超跌反弹机会）
       BB_Score: 价格在下轨→100分, 上轨→0分
```

### 3.3 成交量因子 (20%权重)

```
Volume_Score = 量比因子调整
  量比 = 5日均量 / 20日均量
  量比>1.5: 放量确认 → 权重×1.2
  量比<0.8: 缩量底部 → 均值回归权重×1.3
```

### 3.4 综合评分

```
最终方向 = T值方向 (来自B2v6 DC层)
Comprehensive_Score = Momentum×0.40 + MR×0.30 + Volume×0.20 + Time×0.10
```
